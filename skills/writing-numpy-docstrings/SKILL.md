# Writing NumPy Docstrings

## Overview

A docstring is a contract; its Examples are tests. **Core principle:** every public docstring states behavior the name does not already say, lists every exception the caller must handle, and ships Examples that `pytest --doctest-modules src` executes and passes.

`interrogate` only checks that a docstring *exists*. A docstring written just to turn the gate green (`"""Treina o modelo."""` on `train_model`) passes CI and documents nothing.

## Docstring Contract

Write sections in this order. Every header stays in **English**, module docstrings included (`Functions`, not `Funções`), because the numpydoc parser only knows the English names. The body is pt-BR:

1. **Summary line**: one sentence that adds what the name does not say: the rule, the unit, the side effect ("preservando a original", "aprendidos no treino").
2. **Parameters**: `name : type[, optional]`, then meaning, valid range, and `by default X`. Names must match the signature exactly.
3. **Returns** (or `Yields`): type + shape/columns + invariants. A tuple lists each element.
4. **Raises**: every exception raised in the body *and* the ones that propagate on purpose (e.g. sklearn `ValueError` on stratify). Omit only if nothing can raise.
5. **See Also / Notes**: optional; leakage caveats, NaN behavior, complexity.
6. **Examples**: required on public API. Contract for each example:
   - **Self-contained**: build every input inside the example (`df = pl.DataFrame(...)`). Never reference `df`, `trainer`, `X_train` that the docstring did not create.
   - **Every call that returns a value shows its output**. A bare `>>> f(df)` with nothing under it fails.
   - **Stable output**: `.to_list()`, `.rows()`, `.shape`, small arrays; not a full DataFrame or model repr. NumPy 2 scalars print as `np.float64(0.667)`, and `round()` keeps that type, so convert first: `round(float(v), 3)`.
   - **Deterministic**: pass `random_state`/`seed` explicitly.
   - **One error path** from Raises shown with `Traceback (most recent call last):` and the full `module.Exception: message` line. For an exception raised by a third-party library, whose message changes across versions, add `# doctest: +IGNORE_EXCEPTION_DETAIL`.
   - For I/O, network, or long training: an example on a 5-row synthetic input, not `# doctest: +SKIP`.

**Classes:** document constructor parameters and `Raises` in the class docstring, and put no docstring on `__init__` (`ignore-init-method = true` + mkdocstrings `merge_init_into_class`). Documenting both duplicates the page.

## Implementation

```python
class ColumnNotFoundError(KeyError):
    """Sinaliza que uma coluna exigida pela transformação não está no DataFrame."""


def compute_zscore(df: pl.DataFrame, column: str) -> pl.DataFrame:
    """Padroniza uma coluna numérica em z-score, preservando a original.

    Parameters
    ----------
    df : pl.DataFrame
        Dados de entrada; não é modificado.
    column : str
        Nome da coluna numérica a padronizar.

    Returns
    -------
    pl.DataFrame
        Cópia de ``df`` com a coluna extra ``f"{column}_z"`` (desvio amostral, ``ddof=1``).

    Raises
    ------
    ColumnNotFoundError
        Se ``column`` não existir em ``df``.

    Examples
    --------
    >>> df = pl.DataFrame({"renda": [1000.0, 2000.0, 3000.0]})
    >>> compute_zscore(df, "renda")["renda_z"].to_list()
    [-1.0, 0.0, 1.0]
    >>> compute_zscore(df, "idade")
    Traceback (most recent call last):
        ...
    features.scaling.ColumnNotFoundError: "Coluna 'idade' ausente; disponíveis: ['renda']"
    """
    if column not in df.columns:
        logger.error("Coluna ausente para z-score: %s", column)
        raise ColumnNotFoundError(f"Coluna '{column}' ausente; disponíveis: {df.columns}")
    col = pl.col(column)
    return df.with_columns(((col - col.mean()) / col.std()).alias(f"{column}_z"))
```

The exception line uses the import path without `src.` (`pythonpath = ["src"]`), exactly as pytest imports the module.

## Tooling (pyproject.toml + mkdocs.yml)

```toml
[tool.pytest.ini_options]
doctest_optionflags = ["NORMALIZE_WHITESPACE", "ELLIPSIS", "NUMBER"]  # NUMBER: 0.333 casa com 0.3333...

[tool.interrogate]
fail-under = 90
ignore-init-method = true   # parâmetros ficam na docstring da classe
ignore-magic = true

[tool.ruff.lint]
extend-select = ["D"]
[tool.ruff.lint.pydocstyle]
convention = "numpy"
```

```yaml
plugins:
  - mkdocstrings:
      handlers:
        python:
          paths: [src]
          options: {docstring_style: numpy, merge_init_into_class: true}
```

`docs/reference/features.md` contains `::: features.scaling`.

Examples you wrote but did not run are not done. "Should be stable" is a guess, so run all three:

```bash
uv run pytest --doctest-modules src   # the path is required: with testpaths=["tests"], a bare run collects zero doctests and still passes
uv run interrogate -vv src            # lists what is still missing
uv run mkdocs build --strict          # fails on "Parameter 'x' does not appear in the function signature"
```

Add the doctest command as its own step in CI and the Makefile (REQUIRED SUB-SKILL: scaffolding-ds-projects).

## Common Mistakes

| Mistake | Symptom | Fix |
|---|---|---|
| Summary restates the name (`"""Calcula o z-score."""`) | Docs page says nothing new | State rule, guarantee, or side effect |
| No `Raises` section | Caller never handles the error | List every raised/propagated exception |
| Example uses an undefined `df`/`trainer` | `NameError` in doctest | Build inputs inside the example |
| `>>> f(df)` with no output line | Doctest fails: got a repr, expected nothing | Show output, or assign and inspect `.shape`/`.to_list()` |
| `pytest --doctest-modules` without `src` | "passed" but 0 doctests ran | Pass `src` explicitly |
| Translated headers (`Parâmetros`, `Retorna`) | ruff and mkdocs stay green; page renders plain text | Headers in English, body in pt-BR |
| Docstring on both class and `__init__` | Parameters shown twice in docs | Class docstring only |
| `+SKIP` or `exclude` to reach 90% | Green gate, untested/undocumented API | Fix the docstring; never lower the gate |
| `round(np_value, 3)` or full DataFrame repr | Got `np.float64(0.667)`; flaky across versions | `round(float(v), 3)`, `.to_list()`, `NUMBER` flag |
